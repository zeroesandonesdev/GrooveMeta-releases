# GrooveMeta

GrooveMeta is a music tag editor and renamer for Windows: edit tags and cover art, rename
files and folders from their tags, and look albums up online.

This repository holds only the downloads. Get the latest version from
**[Releases](https://github.com/zeroesandonesdev/GrooveMeta-releases/releases/latest)**:

- **GrooveMeta-x.y.z-setup.exe** is the installer, and the recommended download. An installed
  copy can update itself (Help ▸ Check for Updates).
- **GrooveMeta-x.y.z-win64.zip** is the same program without installing: unzip it and run
  `GrooveMeta\GrooveMeta.exe`.

The installer isn't code-signed yet, so Windows may say "Windows protected your PC". Click
**More info ▸ Run anyway**.

GrooveMeta checks this page for new versions (you can turn that off in Settings ▸
Preferences). The check sends nothing but GrooveMeta's version number.
